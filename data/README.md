# 模拟数据来源与口径

本目录完全由 scripts/generate_demo.py 生成，不包含真实酒店、房客、生日、姓名、手机号、身份证号或交易数据，也未导入公开参考项目的 SQL。

- week.json：固定种子 20261106；8 间模拟房、10 夜库存、7 个到店日的 75 条需求。每日需求量、房型混合比例、儿童组合和价格为人为设定，不是从真实数据估计的模型。
- upgrade_counterexample.json：人为构造的三单反例，证明贪心升级可能降低接受订单数。它不是从统计结果中筛选出的异常案例。
- 所有价格使用整数分，只用于模拟成本差。年龄是入住时匿名合成年龄，不含个人生日。
- 请求处理顺序按 JSON 数组保留；这会影响贪心结果。房间输入顺序不影响结果，最终用稳定房号破同分。
- 每晚库存、停用房晚、辅助用品、保护数量均可手工修改，但日期必须 YYYY-MM-DD，数组必须是真正数组。房型最大入住人数等不是现实合规结论。

python scripts/generate_demo.py --output-dir data 可重新生成相同文件。测试确认同版本生成器和种子产生字节一致的保存输入；结果 JSON 包含输入 SHA-256，便于追踪实际运行所用内容。
